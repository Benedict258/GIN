# GIN Core Move Package

This package is the first smart-contract layer for GIN on Sui / EVE Frontier.

Current scope:

- shared `GinState`
- admin capability
- publishable intelligence artifacts
- contributor credit receipts

The immediate purpose is to give GIN an on-chain anchor for:

- Walrus-backed intelligence artifacts
- contributor reward receipts
- future assembly-linked or world-facing integration
