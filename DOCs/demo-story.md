# Demo Storyline

Use this script while presenting inside the Frontier client to keep the audience anchored to a single tactical thread.

1. **Ikora Corridor Spike**
   - Start in the Report Feed and show a scout log tagged `Ikora Corridor`.
   - Submit a fresh confirmation report so the credits ledger updates in real time.
2. **Advisor Snapshot**
   - Trigger an Advisor snapshot; point to the Walrus proof link for authenticity.
   - Highlight that only Advisor tier contributors can mint this artifact.
3. **Faction Posture Update**
   - Open the Pack Intelligence panel (unlocked via credits) and show how allied packs divert convoys.
   - Call out the Pack Access chips so the audience sees what is still locked.
4. **Access Economy Reminder**
   - Open the Credits panel to show lifetime credits and the “credits to next tier” countdown.
   - Mention that buyers can acquire credits outright if they need instant intel.

End the demo by returning to the Shared Pack view and summarizing how credits, tiers, and Walrus proofs create trust for EVE Frontier fleets.
